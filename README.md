# 替死图腾 (Totem of Substitution)

## 简介
替死图腾是一个Minecraft模组，为游戏添加了一个新的图腾物品。这个图腾可以将致命伤害转移给其他生物，从而保护持有者免于死亡。

## 功能
- **替死效果**: 当玩家受到致命伤害时，图腾会将伤害转移给附近的生物或绑定目标
- **目标绑定**: 可以通过攻击特定生物来绑定替死目标
- **范围效果**: 在10格范围内寻找替死目标（Boss战时范围扩大到20格）
- **治愈恼鬼**: 使用不死图腾治愈恼鬼可以获得替死图腾

## 获取方式
1. 使用不死图腾治愈恼鬼，将其转化为悦灵
2. 治愈后会获得一个替死图腾

## 进度
1. **替死之道**: 获得并使用替死图腾
2. **终极替死**: 用替死图腾绑定末影龙和凋零
3. **替死之力**: 用替死图腾转移超过15点的伤害
4. **救死扶伤**: 用替死图腾救下其他玩家

## 特殊机制
- 无法对铁傀儡和雪傀儡使用（它们没有灵魂）
- Boss战时会自动扩大搜索范围
- 使用时会触发类似不死图腾的特效
- 只在受到致命伤害时生效并消耗

## 注意事项
- 图腾必须在主手或副手持有才能生效
- 使用后会消耗一个图腾
- 需要有可用的替死目标才能生效
